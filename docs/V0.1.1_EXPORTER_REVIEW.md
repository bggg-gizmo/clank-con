## Actual changes
- New Transcript.java recognizes supplied ACE v1 objects and nonempty AI Exporter-compatible role/content JSON arrays; retains supplied order, labels, message content, timestamps, model, supplied thinking and citations where present. Original JSON remains appended to rendered text and unchanged in encrypted storage and exact-byte JSON/ZIP exports. No inference of provider identity or completeness.
- Vault.render recognizes these formats for existing and newly imported JSON records. Unrecognized data stays raw. Existing ChatGPT graph rendering and branch exploration remain. Structured input conversion is capped at nesting depth 64; existing 16 MiB original text processing limit remains. Original byte preservation unaffected.
- Import page explains supported JSON shapes. All seven existing export writers remain; they use the same rendering path for text-based outputs.
- VersionCode 2 / versionName 0.1.1, unchanged package, icon, minimum API, permissions, existing development signing certificate, vault schema and key alias. Device update/data migration test remains pending.
- Original v0.1.0 and diagnostic APKs unchanged. No new dependencies, Gradle, SDK installation, LFS, Actions or hosted build.
